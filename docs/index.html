Установка за минуту

Без прав администратора, без лишних вопросов.

Скачайте Lumora-Setup.exe из раздела Releases на GitHub.
Запустите, выберите папку и нажмите «Установить».
Откройте Lumora с рабочего стола — по умолчанию стоит анимация «Lumora — частицы».
По желанию добавьте коллекции: аниме-арты и видео, установщики лежат отдельно.
